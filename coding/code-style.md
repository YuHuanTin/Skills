# 代码风格

- 只用 utf-8 编码，不允许 BOM，中文不能出现乱码或 ??
- 精简代码时不要乱删注释；代码改了，注释跟着一起改
- 不要过度写测试，只在明说的情况下写有意义的测试，不写细枝末节的测试
- 同时检查有没有冗余的代码和字段，有就清理掉，尽可能复用代码
- 除非用户说明，否则不捏造，不瞎猜，错误路径或不符合用户要求时写抛错代码用于排除问题而不编写强行兜底代码
- 模块级初始化代码必须集中放置，禁止夹在函数或类定义之间；依赖函数或类的初始化统一放在所有依赖定义之后
- 全局对象必须在其依赖的枚举、函数或类定义之后初始化
- 导入只放在文件顶部，不在函数或类内部导入
- 代码布局为
```
模块说明
导入

不依赖函数或类的枚举、常量、映射、对象

内部函数
类

依赖函数或类的全局对象初始化
导出函数
主程序入口（模块则没有）
```
